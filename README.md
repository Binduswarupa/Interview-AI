# AI Interview Preparation Bot

An AI-powered interview preparation assistant that generates technical interview questions and evaluates candidate answers using Generative AI.

## Features
- AI-generated interview questions
- Answer evaluation
- Feedback and scoring
- Multiple technical topics

## Tech Stack
- Python
- Streamlit
- Google Gemini API
- Generative AI

## Run the Project

Install dependencies

pip install -r requirements.txt

Run the app

streamlit run app.py
